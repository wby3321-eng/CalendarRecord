## 一、产品定位与价值

以「日历视图」为核心的个人成长记录平台，统一承载 **计划 / TODO / idea / reading / 收藏** 等多类型信息，跟踪任务进度与收获，支持拖拽改期、延期高亮、标签归类、周期性复盘，并借助 AI 对当前筛选数据做趋势 / 分布 / 复盘 / 预测分析。

面向 **≤5 人的小团队 / 个人**：管理员预置、注册限流到 5 人、数据按账号隔离。

---

## 二、用户角色与权限

| 角色 | 来源 | 权限 |
| :-- | :-- | :-- |
| 管理员 | 系统预置（默认 `admin` / `admin123`，可经环境变量改） | 增删改查全部用户数据；左侧**用户竖栏**切换查看指定用户；聚合查看全部用户（卡片标注归属）；可编辑内置类型 |
| 普通用户 | 自助注册（用户总数 `<5` 才允许） | 仅增删改查本人数据与本人自定义类型；不可见/操作他人数据 |

- 登录账号 `username` 注册后固定不可改；显示名 `nickname` 可改。
- 鉴权：JWT 存 httpOnly Cookie（7 天）；所有业务接口强制校验并按 `owner_id` 隔离。

## 三、功能需求

### 3.1 日历视图
- 三种视图：**周历（默认）/ 月历 / 自定义起止**；以**周一为一周之首**；粒度到「日」，不含具体时间。
- 月历对齐为整月网格（补齐到周一起、周日止）。
- 顶部工具栏：视图切换、日期前后导航、自定义起止日期选择、搜索框。
- 空日期弱化：可选 `dim`（仅视觉变淡）或 `shrink`（缩小格子高度）两种样式。

### 3.2 节假日 / 调休
- 依赖 `chinese-days` 库：法定节假日显示**红标 + 节假日名称**；调休上班日显示**蓝标「调休上班」**。

### 3.3 任务类型管理
- **5 类内置类型**：计划、TODO、idea、reading、收藏（全局可见，`owner_id=NULL`）。
- **自定义类型**：独立颜色 + icon（emoji 或图标名），支持增 / 改 / 删；删除后其下任务的类型置空（变"未分类"，任务保留）。
- **扩展字段定义**（`field_defs`）：每种类型可定义字段，字段类型含 **文本 / 链接 / 图片 / 文件 / 多行文本**。
- 内置类型仅管理员可编辑、且不可删除。
- 入口：类型图例区（chip 栏），非独立工具栏按钮。

### 3.4 任务信息与卡片
- 任务默认字段：任务名称（必填）、链接、结论、状态、优先级、创建时间、计划开始日、计划完成日、实际完成时间、改期次数、扩展字段、附件。
- 类型图例 chip：点击切换该类型显隐 + 显示计数；提供快捷编辑入口。
- 每日格子下有「＋ 新增任务」入口。
- 卡片展示：状态圆点、类型 icon、标题、🔗（有链接则新窗口打开）、优先级三色 pill、延期徽章、结论预览（前 20 字，hover 看全文）、已完成显示 ✅；管理员聚合查看时标注归属用户。
- 两种卡片配色模式：`default`（常规）/ `typeColor`（按状态深浅呈现类型色）。

### 3.5 标签系统（新增，原文未涵盖）
- 标签为**全局数组**，存于任务 `ext_fields["tags"]`，不做类型级配置。
- 录入归一化：trim、去空、去重（不区分大小写保留首次）、单标签 ≤16 字、每任务 ≤10 个。
- 录入交互：任务编辑弹窗标题区就地录入（`编辑任务 #tag1 #tag2 ＋标签`），Enter / 逗号添加、× 删除、聚焦联想已有标签；报刊卡片底部亦可就地增删。
- 展示：`#标签` chip，按标签文本哈希生成**稳定配色**（同名同色）。
- 日历卡片默认隐藏标签（使用频率低）；搜索结果保留标签。

### 3.6 搜索与过滤
- 类 GitHub Issue 语法：`status:done type:计划 tag:重点 关键词`。
- 同名 token 取并集；剩余文本对 **任务名 / 链接 / 结论** 模糊匹配；多条件取交集。
- `tag:` 在后端 Python 侧对 `ext_fields["tags"]` 做不区分大小写子串匹配。
- 类型图例可叠加做本地显隐过滤。

### 3.7 标签云（新增）
- 类型图例区「🏷️ 标签云」按钮打开居中弹窗。
- 圆形词云（螺旋填充算法），字号与 `sqrt(标签出现次数)` 成正比，颜色沿用标签哈希色。
- 点击某标签 → 自动把搜索框填为 `tag:xxx` 并触发搜索。

### 3.8 报刊日报视图（新增）
- 点击某日进入「成长日报」浮层：杂志式不规则版面（CSS Grid + JS 行跨度瀑布布局），头条整幅、重点内容加宽双栏。
- 头部显示日期、星期、节假日 / 调休标记、当日完成度圆环（完成数 / 总数）。
- 就地编辑：点击标题 / 结论 / 标签即可原地修改；卡片支持拖拽调序（localStorage 持久化版序）。
- 图片：支持粘贴 / 拖拽 / 按钮上传，点击看大图（左右切换、Esc 关闭）；可删除。
- 支持全屏 / 还原切换（状态持久化）。

### 3.9 快捷交互
- **状态循环**：待办 → 进行中 → 已完成，可逆序回退（切离"已完成"会清空实际完成时间）。
- **拖拽三语义**：
  - 拖**主体** → start/due 同步平移；整体后移则改期次数 +1。
  - 拖**右缘** → 只改计划完成日（不计延期），形成跨天甘特跨度。
  - 拖**左缘** → 只改计划开始日（不计延期）。
- **延期高亮**：`未完成 且 (今天 > 计划完成日 或 改期次数 ≥ 阈值)` 时高亮；有次数显示「图标+数字」，无次数仅图标；完成后取消高亮。阈值默认 3，用户可自定义。
- 提供「重置改期次数」操作。

### 3.10 跨天任务与甘特展示
- 跨天任务始终视为同一任务，在日历上按计划开始日落位，跨 `start~due` 渲染甘特跨度条，跨行分段续接。
- 两种甘特模式：`lane`（保留泳道条，超出转卡片）/ `card`（全部作为带甘特标志的卡片）；泳道条数可配置（1~6）。

### 3.11 AI 分析
- 以**当前筛选数据**（视图范围 / 搜索 / 指定用户）为上下文，最多 200 条。
- 4 个预设提示词：**进度趋势 / 分布分析 / 阶段性复盘 / 预测报告**，另支持自定义提示词。
- 后端调智谱 GLM（OpenAI 兼容接口），**SSE 流式**返回，前端 Markdown 渲染；可中途停止。
- 未配置密钥时返回友好提示，不报错。

### 3.12 文件附件
- 通过 FastAPI UploadFile 上传图片 / 文件至本地卷；单文件上限 20MB。
- 下载 / 访问经受保护端点并校验归属。

### 3.13 展示与个性化设置
- 用户设置面板由右上角**昵称块**（头像+昵称+下拉箭头）触发，非独立齿轮按钮。
- 可设置：延期阈值、卡片配色模式、甘特模式、泳道条数、空日期弱化样式、修改昵称。
- 管理员专属：左侧**用户竖栏**（UserRail）切换 / 聚合查看，支持眼睛图标手动折叠 / 展开，状态持久化到 localStorage。

## 四、核心实体

| 实体 | 关键字段 |
| :-- | :-- |
| 用户 User | id、username（登录名，唯一不可改）、nickname、password_hash、role（user/admin）、created_at、updated_at |
| 类型 TaskType | id、owner_id（内置为 NULL）、name、color、icon、is_builtin、field_defs(JSON)、时间戳 |
| 任务 Task | id、owner_id、type_id、title、link、conclusion、status、priority、created_at、plan_start_date、plan_due_date、actual_done_at、reschedule_count、ext_fields(JSON，含 tags)、updated_at、attachments |
| 附件 Attachment | id、task_id、kind(image/file)、url、filename、size、created_at |

## 五、关键业务规则
- 状态三循环可逆序切换；切离"已完成"时清空 `actual_done_at`，切入"已完成"时写入当前时间。
- 跨多天任务始终视为同一任务；日历按计划开始日显示。
- 拖主体后移计入改期次数；拖左 / 右缘不计延期，仅调整区间 / 生成甘特跨度。
- 计划完成日不得早于开始日（创建 / 更新 / 拖拽均校验）。
- 注册时用户总数须 `<5`，否则拒绝；用户名唯一。
- 内置类型：普通用户不可改 / 不可删；管理员可改但不可删。

## 六、非功能需求
- **响应式**：适配 PC / 移动端；通用蓝色 SaaS 风格，浅灰底 + 蓝色主色（`#2563eb` 系）、系统字体、圆角与多层阴影。
- **安全**：登录鉴权（JWT httpOnly Cookie）+ 按 `owner_id` 数据隔离；上传 / 下载校验归属。
- **部署**：Docker Compose 云端部署（Caddy + API 两服务）。
- **App 独立应用**：后续扩展，暂不开发。
